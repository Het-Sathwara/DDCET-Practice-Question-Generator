2. System randomly picks from the 1000+ questions in that category
3. Every session gets different questions
4. Virtually unlimited variety

## 🚀 Future Expansion

To add more questions to any topic:
1. Open the JSON file (e.g., `trigonometry_bank.json`)
2. Add questions to the appropriate difficulty array
3. Save - Done!

Example:
```json
{
  "hard": [
    {
      "question": "Your new JEE Mains question here",
      "answer": "Answer",
      "solution": "Step-by-step solution",
      "type": "advanced"
    }
  ]
}
```
