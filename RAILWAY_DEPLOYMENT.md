## Deployment Steps (2 Minutes)

### Step 1: Sign Up on Railway

1. Go to **https://railway.app**
2. Click **"Start a New Project"**
3. Click **"Login With GitHub"**
4. Authorize Railway to access your repositories

### Step 2: Create New Project

1. Click **"New Project"**
2. Select **"Deploy from GitHub repo"**
3. Choose **"DDCET-Practice-Question-Generator"**

### Step 3: Configure (Automatic!)

Railway automatically detects:
- ✅ Python runtime
- ✅ Requirements.txt
- ✅ Procfile settings

**No configuration needed!** It just works.

### Step 4: Generate Domain

1. Go to your project
2. Click on your service
3. Go to **"Settings"** tab
4. Scroll to **"Domains"**
5. Click **"Generate Domain"**

Your URL will be something like:
```
https://ddcet-question-generator.up.railway.app
```

### Step 5: Deploy

1. Railway automatically starts deploying
2. Watch the deployment logs in real-time
3. Wait 1-2 minutes
4. Done! ✅

## Custom Domain

1. Go to **"Settings"** → **"Domains"**
2. Click **"Custom Domain"**
3. Add your domain
4. Update DNS records
5. FREE HTTPS!

## Environment Variables

1. Click on your service
2. Go to **"Variables"** tab
3. Add variables
4. Auto-redeploys!

## Auto-Deploy

Push to GitHub → Railway auto-deploys:

```bash
git add .
git commit -m "Update"
git push origin main
# Railway deploys automatically!
```
